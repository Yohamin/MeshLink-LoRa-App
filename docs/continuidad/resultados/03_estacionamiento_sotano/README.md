# Escenario 3: estacionamiento en sótano

Descripción histórica: estacionamiento universitario en sótano, prueba
horizontal a 50 m y repetidor aproximadamente al medio, NLoS. No es el
antiguo escenario vertical de ascensor.

Copia local: `../privado/escenario_03_estacionamiento/registro_original.txt`.

correspondientes a mensajes 1-10, porque se capturaron intentos anteriores.
No aplicar un filtro de diez líneas: delimitar mensajes/IDs y correlacionar.

tiempo medio de confirmados 1619,86 ms, RSSI RX -101,40 dBm y SNR RX 9,88 dB.
